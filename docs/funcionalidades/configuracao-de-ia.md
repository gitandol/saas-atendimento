# Configuracao de IA

Esta tela define como a assistente responde e conecta a empresa a OpenAI.

## Como configurar

1. Escolha o modelo e informe o nome, a personalidade e as mensagens.
2. Informe uma nova chave API somente quando desejar incluir ou substituir a atual.
3. Salve e use **Testar conexao**. Uma chave digitada no teste nao e salva.
4. Use **Remover chave** apenas quando quiser apagar explicitamente a credencial.

A chave existente nunca volta para o navegador. O campo vazio preserva a credencial ja configurada. Falhas de credencial, limite ou indisponibilidade sao exibidas sem detalhes sensiveis.
