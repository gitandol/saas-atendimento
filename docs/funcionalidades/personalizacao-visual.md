# Personalização visual

O layout administrativo oferece cinco paletas e três opções de luminosidade. A escolha altera a interface sem recarregar a página.

## Alterar a aparência

1. Na barra superior, abra o botão de personalização.
2. Escolha uma paleta: azul, esmeralda, violeta, rubi ou âmbar.
3. Selecione a luminosidade: **Claro**, **Escuro** ou **Sistema**.

O modo Sistema acompanha a configuração do dispositivo. A alteração é aplicada imediatamente. Para usuários autenticados, ela também é sincronizada com a conta e restaurada após um novo login. Para visitantes, a escolha fica salva somente no navegador.

## Navegação lateral

Em telas grandes, use **Recolher menu** para liberar espaço. Em celulares, o botão de menu abre a navegação como um painel lateral; toque fora do painel ou pressione Esc para fechá-lo.

Todos os controles podem ser usados por teclado e exibem foco visível.

## Se a preferência não for sincronizada

A interface continua usando a escolha salva no navegador. Verifique a conexão e tente selecionar a preferência novamente. Nenhum dado de autenticação ou segredo é guardado junto com o tema.
